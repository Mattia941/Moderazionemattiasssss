# SecretOp Plugin
Un semplice plugin Spigot/Paper per Minecraft che permette a un giocatore autorizzato di riottenere i privilegi di OP tramite il comando segreto `/opme`.

## Come usarlo
1. Modifica il nickname in `src/main/java/com/tuonome/secretop/Main.java` sostituendo `"TuoNome"` con il tuo nome in-game esatto.
2. Compila il progetto con Maven (`mvn clean package`).
3. Prendi il file `.jar` generato nella cartella `target/` e mettilo nella cartella `plugins` del tuo server Minecraft.
